Politique de confidentialité

BreachSix: Tactical Squad — BreachSix Games

Aucun serveur, aucun compte

BreachSix: Tactical Squad ne dispose d'aucun serveur, base de données ou compte utilisateur. Le jeu fonctionne entièrement sur votre appareil.

Données stockées localement

Le jeu enregistre certaines informations directement sur votre appareil (jamais transmises à nous ni à un tiers, sauf tel que décrit dans la section publicité ci-dessous) :

  • Meilleurs scores par niveau
  • Skins d'armes débloqués
  • Composition de vos escouades
  • Préférences de jeu (langue, son, musique)

Ces données sont stockées via le stockage local de votre navigateur (localStorage). Si vous jouez dans Telegram, elles sont aussi mirées vers DeviceStorage, le stockage persistant propre à Telegram, pour éviter les pertes de progression liées au fonctionnement des mini-applications Telegram.

Désinstaller l'application ou effacer les données de votre navigateur supprime définitivement ces informations. Il n'existe actuellement aucune sauvegarde infonuagique ni synchronisation multi-appareil.

Achats intégrés

Le jeu ne propose actuellement aucun achat intégré ni transaction financière.

Enfants

Le jeu ne collecte sciemment aucune donnée personnelle identifiable auprès de qui que ce soit, y compris des enfants.

Vos droits

Puisque toutes les données de jeu restent sur votre appareil, vous pouvez les effacer à tout moment en désinstallant l'application ou en effaçant les données du site dans votre navigateur. Pour toute question concernant cette politique, écrivez-nous à breachstudios.dev@gmail.com.

Juridiction

Cette politique est régie par les lois applicables au Québec, Canada (à confirmer).
